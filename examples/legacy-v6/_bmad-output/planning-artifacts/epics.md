# Legacy shop - Epic Breakdown

## Overview
Two epics: accounts first, then orders.

## Epic List

## Epic 1: Accounts
People can sign up, sign in and recover their account.

### Story 1.1: User signup
As a visitor, I want to create an account, so that I can check out faster.

**Acceptance Criteria:**
**Given** the signup form **When** I submit a valid email **Then** my account is created

### Story 1.2: Password reset
As a user, I want to reset my password by email, so that I can get back in.

### Story 1.3: Profile page
As a user, I want to edit my profile, so that my details are current.

### Story 1.4: Delete account
As a user, I want to delete my account, so that my data is gone.

**Prerequisites:** Story 1.1

## Epic 2: Orders
People can see what they ordered.

### Story 2.1: Order history
As a customer, I want to see past orders.
